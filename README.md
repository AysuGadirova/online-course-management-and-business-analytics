# Online Course Management & Business Analytics

## Project Overview

The project includes database creation, table relationships, data insertion, and SQL queries to extract meaningful insights. It demonstrates practical use of SQL concepts such as JOINs, GROUP BY, aggregate functions, subqueries, and analytical queries.

## Key Areas of Analysis

- Student enrollment and course popularity
- Teacher performance and course revenue
- Student academic performance and assignment results
- Payment status, revenue, and refund analysis
- Lesson completion rates and course progress
- Student distribution by city

## Tools & Technologies

- Oracle SQL
- SQL Developer

## Project Goal

To apply SQL skills in a practical business scenario and generate meaningful insights to support educational platform management and decision-making.
